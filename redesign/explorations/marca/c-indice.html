C / Concepto

Índice. Todo es información, nada sobra.

La marca se comporta como una buena herramienta: texto pequeño y exacto, listas en vez de tarjetas, monoespaciada para los datos y un modo oscuro de primera clase. El único color es el verde de "disponible": cuando algo está vivo, se nota.
